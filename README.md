# Learn Python: The Basics

A hands-on starter kit. Each file teaches one topic with short examples, then
gives you **exercises** to fill in. When you run a file, it checks your answers
and prints `PASS` or `FAIL` for each one.

## Setup

1. Install Python 3 from https://www.python.org/downloads/ (on Windows, tick
   **"Add Python to PATH"** during install).
2. Install an editor. [VS Code](https://code.visualstudio.com/) with the Python
   extension is a good choice.
3. Open this folder in your editor or a terminal.

## How to use it

Work through the files in order:

| File | Topic |
|------|-------|
| `01_variables_and_types.py` | Variables, numbers, strings, booleans, `print`, `input` |
| `02_strings.py` | String methods, slicing, f-strings |
| `03_conditionals.py` | `if` / `elif` / `else`, comparison and logic operators |
| `04_loops.py` | `for`, `while`, `range`, `break`, `continue` |
| `05_functions.py` | Defining functions, parameters, return values, defaults |
| `06_lists_and_dicts.py` | Lists, tuples, dictionaries, sets |
| `07_classes.py` | Classes, objects, methods (intro to OOP) |
| `08_mini_project.py` | Put it all together: a number-guessing game |

For each file:

1. **Read** the examples at the top. Run the file to see what they print:
   ```
   python 01_variables_and_types.py
   ```
   (On some computers the command is `python3` or `py`.)
2. **Find** each `# TODO` and replace `pass` with your own code.
3. **Run** the file again. Keep going until every check says `PASS`.
4. **Experiment.** Change the examples, break things, read the error
   messages. That's how you learn.

Stuck? Peek at `solutions.py`, but try for at least 10 minutes first.

## Tips

- Indentation matters in Python. Use 4 spaces per level.
- Read error messages from the bottom up: the last line says what went wrong,
  the lines above say where.
- `print()` is your best debugging tool. Print variables to see what they hold.
- Try things out quickly in the interactive shell: type `python` in a terminal,
  then type code line by line. Type `exit()` to leave.
